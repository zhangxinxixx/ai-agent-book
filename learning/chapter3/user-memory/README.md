# User Memory 用户长期记忆实验

这个目录整理了 Chapter 3 的实验 3-1 / 3-2：用户长期记忆。

实验把系统分成两条链路：前台 Agent 负责对话并保存原始记录，后台 Agent 负责从新对话中提炼长期记忆。这样可以让新会话使用旧信息，同时避免把全部历史对话反复塞进上下文。

## 上传范围

本目录保留可复现代码和公开学习材料，没有上传：

- `.env` 和任何真实 API Key；
- `data/` 中的用户对话及记忆文件；
- `logs/`、`results/`、`validation/`、`__pycache__/`；
- 本地运行轨迹和临时输出。

代码来源于本地 `chapter3/user-memory` 当前工作版本，包含用户修改后的中文说明。公开副本把示例中的账号、路由号和联系地址替换成了明显的测试占位符，不改变程序流程。
