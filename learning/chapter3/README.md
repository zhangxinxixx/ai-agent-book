# 第 3 章：用户记忆和知识库

第三章讨论的是：怎样让 Agent 不只记住当前对话，还能在多次会话之间保留有用信息，并从共享知识库中找到可靠证据。

这一章有两条互相关联的主线：

- **用户长期记忆**：保存用户偏好、历史事件、稳定事实和可复用经验。
- **知识库与 RAG**：从外部资料中检索与当前问题有关的内容，再交给模型生成答案。

## 建议学习顺序

1. 先分清当前上下文、会话轨迹、长期记忆和知识库。
2. 再理解用户记忆怎样写入、更新、删除和重新加载。
3. 学习 RAG 的写入链和读取链，以及切块、检索、重排等环节。
4. 最后学习结构化索引、Agentic RAG、记忆治理和评估方法。
